# Welcome to our e-commers web design
👉 [Visit the Live Site](https://effortless-khapse-8ef529.netlify.app)
## 📋 Overview
This is a responsive and user-friendly e-commerce website designed to showcase and sell products online. It includes product listings, a shopping cart interface, and a modern design that enhances the user shopping experience.
### ![image](https://github.com/user-attachments/assets/a4de2805-c4af-4a36-9889-effa2f390515)
## ✨ Features

### 🖼️ Modern & Aesthetic Design
- Clean and elegant UI with beautiful imagery.
- Consistent layout and pleasing color palette.

### 🛒 E-commerce Functionality
- Product cards with:
  - Name
  - Price (discounted and original)
  - Sale labels (e.g., -50%)
  - “New” tags for fresh arrivals
  - ![image](https://github.com/user-attachments/assets/585e114d-7e1c-475a-9da2-fcce3c7e472f)


### 📂 Category Browsing
- Main sections:  
  - **Dining**  
  - **Living**  
  - **Bedroom**
    ![image](https://github.com/user-attachments/assets/f08dd93f-843c-4832-8a95-4c7742118846)


### 🎯 Promotions & Deals
- Dedicated “New Collection” banner with **Call to Action**
- Discounts clearly labeled with red badges

### 🖼️ Room Inspiration
- **“50+ Beautiful rooms inspiration”** slider section
- Inspires users by showing furniture in real-life room designs

### 📸 User-Generated Setups
- **“Share Your Set Up”** gallery  
- Aesthetic room layouts using Furniro products
- ![image](https://github.com/user-attachments/assets/4a5b0f35-3cf2-4344-b7ad-93660e6cf4ac)


### 📱 Fully Responsive Design
- Mobile-friendly, tablet-optimized, and desktop-ready

### 🔗 Navigation & Footer
- Navbar: Home, Shop, About, Contact, Blog  
- Footer with:
  - Address
  - Quick links
  - Payment & Privacy info
  - Newsletter subscription form

---

## 🛠️ Built With

- **HTML5** – For structuring the content.
- **Tailwind 4.1** – For styling and layout design.
- **Netlify** – For free and easy deployment.
